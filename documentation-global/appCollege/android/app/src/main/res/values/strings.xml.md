# strings.xml

## Chemin du fichier
`android/app/src/main/res/values/strings.xml`

## Description
Fichier de ressources string Android. Définit le nom affiché de l'application.

## Composants/clés principaux
- **app_name** : `AppCollege`

## Dépendances
- Référencé par `AndroidManifest.xml`

## Détails importants
- C'est le nom qui apparaît sur l'écran d'accueil Android et dans le gestionnaire d'applications
