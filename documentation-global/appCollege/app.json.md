# app.json

## Chemin du fichier
`app.json`

## Description
Configuration de base de l'application React Native. Définit le nom interne et le nom affiché de l'application.

## Composants/clés principaux
- **name** : `app` — nom interne de l'application
- **displayName** : `app` — nom affiché sur l'écran d'accueil

## Dépendances
Aucune

## Détails importants
- Le nom réel de l'application (AppCollege) est défini dans `android/app/src/main/res/values/strings.xml`
