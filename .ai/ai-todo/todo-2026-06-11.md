### Étape 1 : UX visible par l'utilisateur (écran principal)

**Statut** : TERMINEE

**Objectif** : Simplifier radicalement l'interface. Un seul écran, pas de scroll, pas de badges.

**Ce qui change** :
- Supprimer la barre de connexion "Connecté/Hors ligne" → remplacée par le bouton rond coloré
- Supprimer le badge "X en attente" du header
- Supprimer l'icône ⚙️ gear → remplacée par le bouton rond
- Supprimer le ScrollView + cards → layout simple et épuré
- Supprimer les messages de feedback inline (succès/erreur) → notification toast
- Changer le compteur de taps de 5 → 6 pour accéder aux paramètres

**Layout cible** :

```
┌─────────────────────────────────┐
│                                 │
│  Passage a l'infirmerie      ●  │  ← Bouton rond (vert/rouge)
│                                 │
│  ── Etape 1 sur 3 ──────────   │
│  Tape ton nom de famille        │
│                                 │
│  ┌─────────────────────────┐   │
│  │  DUPONT                 │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```

**Éléments de l'écran** :

| Élément | Type | Comportement |
|---------|------|-------------|
| Titre | Texte statique | "Passage a l'infirmerie", gauche. Pas de tap. |
| Bouton rond | TouchableOpacity | Haut droite. Vert = connecté, Rouge = déconnecté. **6 taps = ouvrir paramètres** |
| Champ Nom | TextInput | Auto-capitalize, placeholder "NOM DE FAMILLE" |
| Champ Prénom | TextInput | Auto-capitalize, placeholder "PRENOM" |
| Bouton Valider | TouchableOpacity | Centré, envoie le scan. Feedback via toast |

**Supprimé par rapport à l'app actuelle** :
- ❌ Icône ⚙️ gear → remplacée par le bouton rond
- ❌ Badge "X en attente" du header
- ❌ Barre de connexion "Connecté/Hors ligne"
- ❌ Messages de feedback inline → remplacés par toast
- ❌ 5 taps sur le titre pour debug → le debug est dans les paramètres

```
│  └─────────────────────────┘   │
│                                 │
│       ┌───────────────┐        │
│       │   VALIDER     │        │  ← Bouton actif
│       └───────────────┘        │
│                                 │
└─────────────────────────────────┘
```

**Comportement** :
- **Rapidité** : L'élève ne doit JAMAIS attendre. Tout est instantané.
- **Etape 1** : Le champ Nom est actif. Le champ Prénom est masqué ou grisé. Un texte guide l'élève.
- **Etape 2** : Le champ Nom devient gris (lecture seule). Le champ Prénom devient actif. Nouveau texte guide. **Transition immédiate** (< 100ms).
- **Etape 3** : Les deux champs sont gris. Le bouton Valider s'affiche et devient cliquable. Texte d'encouragement.
- **Après validation** : Toast de succès (3s), puis retour à l'étape 1 automatiquement.
- **Si erreur** : Toast d'erreur, reste sur l'étape en cours.

**Condition de rapidité** :
- Pas de setTimeout, pas de delay, pas d'animation lente
- Le déverrouillage du champ suivant se fait à la frappe (onChangeText)
- Le bouton Valider apparaît dès que les 2 champs sont remplis
- Toast : 2 secondes max, pas de transition lourde

- Tout fichier hors `appCollege/`
