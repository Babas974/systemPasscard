# Changelog - 2026-06-09

## Correction CI - pnpm not found
- **Problème** : `actions/setup-node@v4` avec `cache: "pnpm"` échouait car pnpm n'était pas encore installé
- **Solution** : Ajout de `pnpm/action-setup@v4` avec `version: 9` AVANT `actions/setup-node@v4`
- **Fichiers modifiés** : `.github/workflows/build.yml`
- **Jobs concernés** : react-tests, android, tauri-linux, tauri-windows

---

## Correction CI - gdk-3.0 not found (rust-tests)
- **Problème** : Le job `rust-tests` échouait car `gdk-sys` ne trouvait pas la librairie GTK 3.0
- **Solution** : Ajout de l'étape `apt-get install libgtk-3-dev libgdk-pixbuf-2.0-dev libatk1.0-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev libwebkit2gtk-4.1-dev` dans `rust-tests`
- **Fichiers modifiés** : `.github/workflows/build.yml`

---

## Correction CI - packages field missing
- **Problème** : pnpm 9 détectait un fichier `pnpm-workspace.yaml` sans champ `packages` et échouait
- **Solution** : Suppression du fichier `dashboard-app/app/pnpm-workspace.yaml` (projet non workspace)
- **Fichiers supprimés** : `dashboard-app/app/pnpm-workspace.yaml`

---

## Correction CI - React Native gradle plugin not found
- **Problème** : Gradle ne trouvait pas `@react-native/gradle-plugin` dans `node_modules` car pnpm ne hoiste pas les packages par défaut
- **Solution** : Création de `appCollege/.npmrc` avec `shamefully-hoist=true`
- **Fichiers créés** : `appCollege/.npmrc`

---

## Build Android release + Icône
- **Problème** : APK en mode debug (nécessite Metro), icône par défaut React Native
- **Solution** :
  - `assembleDebug` → `assembleRelease` dans le workflow CI
  - Génération d'icône téléphone+flèche (style dashboard) pour tous les densities
  - Nom de l'app renommé "app" → "AppCollege"
- **Fichiers modifiés** : `.github/workflows/build.yml`, `appCollege/android/app/src/main/res/values/strings.xml`
- **Fichiers générés** : `appCollege/android/app/src/main/res/mipmap-*/ic_launcher*.png`

## Scan réseau dynamique (Kotlin natif)
- **Problème** : IP du serveur hardcodée, la tablette ne trouvait pas le PC sur le réseau
- **Solution** :
  - Module Kotlin `NetworkModule.kt` : obtient l'IP de la tablette + scan parallèle du sous-réseau (254 IPs en 5s)
  - Enregistrement du module dans `MainApplication.kt`
  - `ApiService.ts` utilise le scan natif au lieu de URLs hardcodées
- **Fichiers créés** : `appCollege/android/app/src/main/java/com/appcollege/NetworkModule.kt`
- **Fichiers modifiés** : `appCollege/android/app/src/main/java/com/appcollege/MainApplication.kt`, `appCollege/ApiService.ts`, `appCollege/App.tsx`
